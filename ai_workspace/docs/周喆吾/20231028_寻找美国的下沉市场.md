# 20231028_寻找美国的下沉市场

作者：周喆吾

[原文链接](https://mp.weixin.qq.com/s/YXffO_COHoSDCEbpeN1-Yg)

沈鹏给我们讲，2015年，他去山东泰安开会，发现订酒店都是走美团的酒旅服务了。他敏锐的察觉到，整个泰安，携程根本就没有房源，而爬泰山都要住在这个城市，是个挺大的旅游景点呢。再问了一圈餐厅服务员，你们出行都用什么订酒店 —— 已经都是美团，没有携程了。

这说明，2015年，传统大型互联网公司，还没来得及把服务覆盖到三线和三线以下的城市，中国下沉市场，大有可为！

于是沈鹏决定离开自己一手创办的美团外卖业务，离开自己和王慧文不辞辛苦拉扯起来的6000人的队伍，转而创办水滴。

为什么选择保险行业做下沉？傲慢的四大老巨头们几十年来都以服务城里人为主，毛利高、动作慢、不懂移动互联网。除了渠道以外，下沉市场所需要的保险产品也是全新的（要能够低成本覆盖大病忽略小病）。

同一个阶段，中国的下沉四大天王 PKQS（拼多多、快手、趣头条、水滴），全都成功在小镇站稳脚跟，在美股港股上市，一时风光无限。

笔者那时候写过一篇文章，感慨道：[为什么互联网行业，阳春白雪总是输给下里巴人？](http://mp.weixin.qq.com/s?__biz=MzU2MTgzMjQyMA==&amp;mid=2247483720&amp;idx=1&amp;sn=3132a8ae10362028866c535bdb6aac1d&amp;chksm=fc7389c3cb0400d5f0d62d83035940de2681bc621d5d70d0dc863bea63d670c8056c7749cab1&amp;scene=21#wechat_redirect)

中国的商业下沉，是一个巨大的PEST（Political、Economical、Societal、Technological）的变革浪潮。2015年之前的下沉市场，不是没有移动支付、移动互联网，而是没有互联网，甚至于没有计算机的市场！中国的一半多的人口经历这样的leap frog，如果能够抓住其中的商机，是有机会能扶摇直上的。除了下沉四大天王，也不乏OPPO/Vivo、极兔快递、蜜雪冰城等头部玩家。好风凭借力、送我上青云。

我们关注中国下沉的时候，读完黄铮写的《把资本主义倒过来》，也必然会联想到毛泽东选集的第一卷第一章《中国社会各阶级的分析》，奠定了以经济地位来做阶级分类的斗争方针。过去的一百年，中国最大的力量，很多来自于无产阶级对更好的生活的追求；所以中国革命最卓有成效的口号是“打土豪、分田地”，落脚点在“田地”上。毛主席将中国人分为贫农、上中下农、小资产阶级、地主和买办阶级，是指导中国革命的最正确的切面：经济阶级切面 —— 以阶级斗争为纲。

基于这些思考，我们来看美国，美国的社会应该怎么分层、分类呢？美国社会是否存在一个广大的被忽略的“下沉市场”呢？

首先，我们发现**美国社会的主要矛盾并不是经济上的**。虽然医保体系和社保体系并不健全，但是一个美国人想要饿肚子还是挺难的 —— 看看40%的肥胖率就知道了，美国的肥胖标准可不是小胖、而是大胖（BMI &gt; 30）。在一个穷人的特征是胖、蓝领的时薪冠绝全球的地方，如果从经济收入和资产上来给美国社会分层分类，似乎不能最有效的把握脉络。

所以回到本篇的主题：谁是美国的下沉人群？

“The Lost Souls”（**失落的灵魂**）

笔者对美国下沉的定义，不是由经济阶级决定的，而是从灵魂归属上判断的。他们有三个主要特征：

**单亲家庭，或成长过程中父母离异的**

注意到，美国非婚新生儿达到了40%，而非裔未婚新生比率居然有72%！难怪对黑人小孩最大的辱骂就是简单的问候：“爸爸去哪了？”

**未生活在宗教辐射下的**

**没有拿到大学学位的**

这些人，主要生活在美国大城市的贫民窟（inner city）和郊区的穷学区内。随着美国大城市的状态恶化（尤其是疫情过后 remote work 占比逐年提升），此人群的占比也在逐年上升，现在显然是超过了半数总人口。

我在美国经常听到白左公开来教训这帮人，说他们是受害者心态（victim syndrome），认为自己生活中的不如意都是别人的问题，应该从自己找原因。

我们客观来说，**失落的灵魂们**（“The Lost Souls”） 所感受到的痛苦，确实有很大比例是来自于环境啊！

没有职业机会、没有倾诉对象、没有自我认同… 吃是吃饱了，但没有盼头，再抬头看看白左精英WASP们，永无出头之日啊…

我们在美国做下沉，做的是心理的下沉，给陷入抑郁、避世、虚无、性别模糊化的美国年轻一代提供慰藉。曾经这个角色是新教徒Protestant、摩门教会LDS来提供的，现在是芬太尼、TikTok来补位，未来可以交给我们。

Presence的使命是打破时空，解放灵魂。在当前的国际分工下，失落的灵魂们已经没有在发达国家找到自己位置的可能了。

美帝国今天之所以没有崩溃，像是百足之虫、死而不僵，又装上了核动力发动机（硅谷创新）。疫情前，还能够用增长掩盖大量问题；现在去旧金山、洛杉矶城里走一走，这些病入膏肓的问题是真的遮不住了。逃到郊区不是办法，工业化回潮也是不可能的。

我们作为反向白求恩，带着国际人道主义精神，希望能够给美国失落的一代，给美国的下沉市场，聊以慰藉罢。在共同发掘美国下沉市场的过程中，一定能再崛起不止四五家上市公司，甚至会出现传世的伟大企业。
