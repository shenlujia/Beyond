这期@Max Zhou  按着我听的podcast对我影响很大 - Ravi的访谈，关于专注，**keep the main thing the main thing**.&nbsp;

一个公司/人可以有5个目标，最可怕的是实现了4个目标的增长，好像大家都很高兴觉得有进展，而最终的1个真正有意义的核心目标没进展没有卵用。

人话版解释是「用战术的勤奋掩盖战略的懒惰」。

我们的大脑过于「聪明」，不喜欢深度思考的不舒服的感觉，于是很容易让身体勤奋，娱乐/摸鱼还有罪恶感，那就做看起来有进展的fake work好了 ┓(&nbsp;´∀`&nbsp;)┏

《认知觉醒》里是👇🏻这样解释的：

理智脑对大脑的控制能力很弱，所以我们在生活中做的大部分决策往往源于本能和情绪，而非理智。

本能脑和情绪脑的基因一直被生存压力塑造着，所以它们的天性自然成了目光短浅、即时满足。又因它们主导着大脑的决策，所以这些天性也就成了人类的默认天性。

社会的发展突然开始加速了。这种变化对于古老的本能脑和情绪脑来说，简直就像一瞬间发生的事情，它们根本没有反应过来。

进化之手还未来得及完全改造我们，这些在远古社会具有生存优势的天性，在现代社会反而成了阻碍，甚至可以说，我们当前遇到的几乎所有的成长问题都可以归结到目光短浅、即时满足的天性上，不过在现代社会，用避难趋易和急于求成来代指它们显然更加贴切。

这期播客里的嘉宾Ravi Gupta之前去 Instacart 做CFO，公司订单、收入等各方面都在增长，大家都很happy，但是Ravi入职一看就吓一跳，UE（单元经济模型）是负的，靠融资疯狂亏钱做规模，这样下去不可持续，公司会倒闭的！

真正最重要的一件事是什么？把UE搞正，**然而完全没有人花时间在这上面...** 于是开始聚焦解决UE问题，用了好几年时间，非常费劲最终一分钱一分钱的把成本扣下来毛利率提上去，终于把公司救活了并升到了COO，后来到红杉资本做合伙人。

也顺藤摸瓜再读了一次播客里推荐的克里斯坦森的《如何衡量你的人生》，有和当年看完全不一样的感触，强推阅读，举了很多商业案例来说明方法论，对工作和个人都有很大启发，挖个坑，改天再更读书笔记。 **很多公司/人失败的原因是做短期的事儿而忽视长期目标**，就做眼前的事儿，因为他们根本没有长期目标。

大佬如Ravi，依然后悔没有更早问自己这个问题：我该如何衡量自己的人生？怎么样我会觉得成功和幸福？

**这个方法也完全适用于公司**。想明白长期目标后，短期很多问题就不再是问题了。一种问题是资源优化分配/ 提高效率问题，另一种问题是做什么、不做什么的问题；每当自己想第一种问题的时候，优先想想第二种问题，其实大部分事都可以不做，都是假动作，振聋发聩啊！

最近开始让团队同学和自己每天上班先写一件，**且只能写一件**最重要的事，你发现其实逼着自己就写一件很难，而且开始的时候一天过去真的最重要的事就没咋花时间，但逐渐大脑会被锻炼的更敢于面对现实：什么是真正的、最重要的一件事？当这一天过去，我会如何衡量这一天，做完什么会让我有真的成就感而不是短暂多巴胺？

听完播客几周后的今天回顾，我花在最重要的一件事上的时间显著提升了:D&nbsp;

比如周末的午后，我在「写写读书笔记/看看书」这样看起来有用的事儿，和拖延了1-2周的「写双月OKR、我们在做的产品成立的核心假设检验方法、产品的意义」之间，我果断选择了先做后者，因为我知道如果做完了，at the end of the day，我会觉得是有真的成就感的。

虽然一开始大脑很抗拒这样不舒服的感觉，但做了以后发现每项任务根本没有想象的难和久，可能2个小时就能完成一件任务到60分，之后再花一些时间后台思考，酝酿改善到7-80分，远比做 fake work 之后的短暂多巴胺要更快乐。

Fake work是让人失去时间和钱的真凶，你可以假装勤奋，但结果不会陪你演戏。

Keep the main thing the main thing, simple but not easy!
