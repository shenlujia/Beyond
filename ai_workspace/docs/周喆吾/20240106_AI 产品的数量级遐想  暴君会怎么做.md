# 20240106_AI 产品的数量级遐想  暴君会怎么做

作者：周喆吾

[原文链接](https://mp.weixin.qq.com/s/vNfzB7ABbr3e4tHQGKUAbQ)

王慧文讲，产品经理一上来就会学到，多数的需求是无法被满足的。正如人们从小就被教育不能飞、不能从高处跌落

然而技术一旦进步，“不能被满足的需求”，可能会变成很好的商业模式

“一骑红尘妃子笑、无人知是荔枝来”，诗里骂唐玄宗是个暴君。但今天美团买菜、盒马生鲜，人人都能吃到岭南的新鲜荔枝。“暴君”只是提前1000年解锁了现代人的生活方式而已...

[王川：论数量就是质量](http://mp.weixin.qq.com/s?__biz=MzA3MzE5MjM2Mw==&amp;mid=2672246961&amp;idx=1&amp;sn=b646d32c92ede71dc8d0c4cec3c2114a&amp;chksm=85a12675b2d6af63e951252337c95e5dc5b75b56b38790b54a7cb0c7dec9fdd3fdaea1213442&amp;scene=21#wechat_redirect)；有些商业模式完全是因为数量级的提升解锁的。

这让我想到另一个暴君，隋炀帝开凿大运河，万人民夫拉船；而这正是近代的蒸汽邮轮呀！

孟姜女哭长城、阿房宫的楚人一炬、可怜焦土，莫不如是... **这些“暴君的想法”，不过是被压抑的凡人也有的需求**，随着技术革命带来数量级的解放，思想上也立刻解放了；今天我们都住在高楼大厦里，一点也没觉得有何不妥。

为什么这些帝王只是要吃点生鲜水果、想住在别墅里、坐个游艇，就要被史家鞭笞千年呢？因为他们的欲望通过压抑其子民来实现；而今天我们同样的需求，能通过机器的性能来满足。

工业革命时代，蒸汽机、火车、起重机，都带来了相比五个数量级的人力，也就对应着，古代暴君要奴役万人才能满足的需求。

LLM带来的 AI 技术革命，很多科学家讲通过了图灵测试，也是前文 [AI 时代错误的商业模式 - “好10倍” 且 “更便宜” 吗？](http://mp.weixin.qq.com/s?__biz=MzU2MTgzMjQyMA==&amp;mid=2247484939&amp;idx=1&amp;sn=3c9537aea57a58b8463ca89109554cbf&amp;chksm=fc738e80cb040796decc8c3e9d0acb79b091cfb5347d4732f8c7e5d38390bd7d67d68e7d4c6e&amp;scene=21#wechat_redirect)里写的白领“人矿”。

大家现在并没有想出来特别好的 LLM 的工作方式，是不是因为忽略了**数量级**的提升？我们经常尝试和**一个** LLM 去对话**，**让**一个** LLM 去写代码，让**一个&nbsp;**LLM 去写文章、做表格，最后吐槽也没多有用。这里面错误的关键词，是不是**“一个”**？

如果是一万个 LLM 同时为你劳作，你能解放些什么之前被压抑的需求呢——&nbsp;想象一下你是古时候的暴君？

这让我立刻想到了《三体》里的人列计算机！用三千万人组成的与门、或门和总线，计算皇帝最关心的... 微积分！
