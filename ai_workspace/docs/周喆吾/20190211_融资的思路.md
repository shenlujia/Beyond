# 20190211_融资的思路

作者：周喆吾

[原文链接](https://mp.weixin.qq.com/s/YsJdUWb9LXujcPBRm0XzNw)

1. 绝对不是多少DAU = 多少Valuation，而是机会有多大，TAM能占多少，中间有几个问题没回答，需要几轮钱和时间来回答。我之前有个产品经理是卖了公司给LinkedIn，在500 startups做了四年advisor，特别强烈的反对了我的DAU*$xx的思路

2. DCM哥跟我又强调一遍估值只取决于second bidder，这个胡森早就很明确了

3. Softbank发现了一个Contrarian秘密：独角兽越来越多，超后期融资越来越大，而整个硅谷每年VC一共投50B，很多一流基金一个fund里只有500mil，那么如果能一个fund 100B，就可以change the game，拿到超额回报，比如主导Grab收购Uber通过巨大资本造出地域垄断。

4. Yuri Milner也发现了Contrarian秘密：如果我不要voting right，不要董事会席位，就可以投进很多大deal里，而实际上growth stage要控制也没啥用 ==》超额回报。

5. a16z、徐小平、朱啸虎和经纬8年前发现了另一个秘密：移动互联网是一堆小公司没准能跑出来，所以主要是coverage，两个方向可以做，一个是VC娱乐化大搞PR，一个是奇怪的雇佣（没财务背景的产品经理、低薪雇海外名校的小姑娘）；到了移动互联网结束的时候，就可以layoff这些人了。

6. 我之前商学院申请的推荐人Vasily给我讲了他发现的另一个秘密：由于独角兽越来越后期，大量的员工股和期权（10-20%）要不然是没有exercise，要不然金手铐锁的很痛苦，而又有小资本想要投独角兽。所以他做了个小fund，给早期员工打个折收购股票，花了20个小时+80个小时lawyer work投了2000万美金，员工得到liquidity，LP得到了五到七折的独角兽股票。

所以我明白了，这帮VC全都在找超额回报，八仙过海各显神通，方法就是根据行业的变化和大家之前的教条，来发掘不对称的机会（Contrarian秘密），去执行，然后profit。
